# AI/ML Internship - Task 2: Exploratory Data Analysis

## Objective

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic dataset using statistical methods and visualizations.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Dataset

The Titanic dataset is used for this analysis.

## EDA Performed

The following analysis was performed:

1. Loaded and inspected the dataset.
2. Checked dataset shape, columns, and data types.
3. Identified missing values.
4. Generated descriptive statistics.
5. Calculated mean, median, and standard deviation.
6. Analyzed categorical features.
7. Created histograms for numerical features.
8. Created boxplots to examine distributions and potential extreme observations.
9. Analyzed survival distribution.
10. Compared survival across gender.
11. Compared survival across passenger class.
12. Analyzed age and fare distributions by survival.
13. Created a pairplot to visualize feature relationships.
14. Created a correlation matrix.
15. Calculated skewness of numerical features.
16. Documented observations and patterns.

## Files

- `Titanic-Dataset.csv` - Dataset used for EDA.
- `eda_analysis.ipynb` - Jupyter Notebook containing the complete EDA.
- `README.md` - Project documentation.

## Conclusion

Exploratory Data Analysis helped understand the Titanic dataset through descriptive statistics and visualizations. The analysis provided insights into feature distributions, relationships, survival patterns, missing values, and potential extreme observations.
